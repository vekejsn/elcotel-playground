Edit settings, not bytes. Your files stay on this computer.

No file open

Open an existing file to get started. Saving creates a new file.

ON asserts the setting's name: for “Disable …”, ON means disabled. Unknown settings stay unchanged.

Call restrictions during scheduled shutdowns

Set schedule 1 with R463/R464 and schedule 2 with R465/R466. Check a box to restrict that call type during the schedule. Other bits are preserved.

What happened to Lo, Hi, Token and Address?

Those are implementation details, not settings to edit. Lo/Hi select which firmware versions the old editor supports; Token/Address describe binary storage. This editor handles them for you.

It validates known editor ranges, converts dollars and times automatically, and checks the result can be read back. That does not prove a setting is suitable for your particular phone or telephone service.

Inline macro programs and settings with unconfirmed meanings or conflicting definitions are read-only here.
